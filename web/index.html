raft-kv · interactive demo

Raft consensus, live in your browser

Five nodes running the same Go Raft implementation as the real server, compiled to WebAssembly and talking over a simulated network. Break things: kill nodes, split the network, lose messages. Then watch the cluster elect a leader and agree on one log again.

Things to try

  1. Kill the leader. The others stop hearing heartbeats, one times out, asks for votes and takes over. Writes keep working.
  2. Strand the leader. Put it in a minority with one follower, then send a write to it with “Send to” below. It accepts the write but can never commit it. Heal the network and watch that entry get replaced.
  3. Lose messages. Turn loss up to 30%. Heartbeats go missing and elections get more frequent, but committed data never diverges.
  4. Find the majority. Kill two nodes and writes still commit. Kill a third and they stall until one comes back.
